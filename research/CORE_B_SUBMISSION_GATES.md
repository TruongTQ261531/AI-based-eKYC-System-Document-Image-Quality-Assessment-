# Submission decision boundaries, recorded before V4 test release

The target is a defensible CORE B submission, not a guaranteed acceptance.
An engineering task cannot determine a programme committee's decision.
These gates describe what the released evidence can support. They do not
replace a venue's current scope, page limits, deadlines or review criteria.

1. **Reproducibility.** Publish the frozen protocol/model lock, ID-disjoint
   roles, source/model hashes, all numerical outcomes, code, actual rerun
   counts and an independent publication/rescoring audit. Every declared
   scheduled run must finish or be identified as missing, never imputed.
2. **Algorithm claim.** Compare the development-selected cascade with raw,
   completion, support box, a second localizer and simple confidence routing.
   Show both readers and both primary sources, ID-clustered intervals,
   costs and review behaviour. If improvement is source-dependent or the
   interval includes zero, restrict the claim accordingly. A standard ridge
   regressor, boosted stumps or confidence cascade alone is not new theory.
3. **Deployment claim.** Measure fresh actual pipeline calls, at most two
   OCR executions per request, rather than presenting reconstructed exhaustive
   candidate costs as online latency. Exercise the localhost UI with real OCR,
   editable observed fields and errors. Mocked camera tests do not establish
   physical-camera or production eKYC/PAD performance.
4. **Dataset claim.** Disclose structural aliases in the six original
   configuration IDs, preserve their results, and test separate true spatial
   layouts plus fixed-model transfer to public photographs. Generated support
   rectangles are not independently annotated human legibility. No fresh
   consented camera collection is currently available, as confirmed by the
   user. This limits external validity even when every automated test passes.
5. **Closest prior.** Compare explicitly with DocAttentionRect/ArbDR,
   DocXPand, SHC/ConfRoute and OCR tool selection. Missing boundaries,
   synthetic identity cards, visible/full references and confidence routing
   already have precedents. The candidate contribution is a narrower auditable
   partial-ID information/cost/review evaluation, whose usefulness and
   distinction must be demonstrated rather than asserted.

For an algorithm paper, retain the superiority claim only where paired
evidence supports it. For a benchmark/evaluation paper, negative algorithm
results can be useful, but a small generated dataset plus ordinary routing
does not automatically establish sufficient novelty. Independent annotation
and consented multi-camera evidence remain concrete strengthening work when
those resources become available. Do not invent those resources or label
public/synthetic images as newly collected data.
